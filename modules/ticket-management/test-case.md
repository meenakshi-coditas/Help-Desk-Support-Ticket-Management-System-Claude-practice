# Test Cases: Ticket Management (`TKT`)

Scope: Create Ticket, My Tickets / All Tickets (search, filter, sort, pagination), Ticket Details, ticket field edit, optional delete, categories, attachments and screen navigation. Source: `specification.md` of this module and `requirement.md`. Requirements covered: REQ-010 to REQ-020, REQ-070, REQ-061, REQ-063, REQ-064.

Many expected values depend on open questions and are marked **Provisional** (limits: subject 150, description 10..5000, attachment 1 file / 5 MB / png, jpg, jpeg, pdf, txt, pageSize default 10 max 100, 404 for other users' tickets, 400 for validation). If the client changes a value, update the affected cases (the open question is cited in the Test Scenario cell, e.g. `[OQ-02]`). Cases for undefined behaviour are marked **Blocked** and must not be executed until the open question is answered.

**Provisional seed data**
- **DS-0 (baseline)**: accounts above; categories id 1 "Technical Issue", id 2 "Billing", id 3 "Account Access", id 4 "General Inquiry", id 5 "Legacy" (inactive) (OQ-12); no tickets; next ticket number 1001 (A-09).

Plus 3 tickets owned by user2: `U2 ticket 1..3`, numbers 1026..1028, Low, category 1, Open.
